Instagram Clone
Description
A full-stack Instagram clone built using React (frontend) and Spring Boot (backend). Features include user authentication, posting images, liking, commenting, and viewing posts.

Features
User authentication (Sign up, Log in)
Post images with captions
Like and comment on posts
User profiles with posts
Feed showing all posts
Technologies
Frontend: React, Redux, Axios
Backend: Spring Boot, Spring Security, MySQL, JPA/Hibernate
Image Storage: Cloudinary or AWS S3
